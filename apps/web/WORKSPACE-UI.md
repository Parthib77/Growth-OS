# Workspace UI direction

The five user-provided screenshots are the visual authority for Customers, Campaigns, Reviews, Results, and Settings. The signed-in Today view and shared navigation inherit the same language. This is an Operate interface for an appointment-business owner who needs to scan records, take a clear next action, and preserve consent and outcome context.

## Direction contract

THESIS: Keep the real workflow and data intact while replacing the old dark, square register design with the supplied bright operating workspace.

OWN-WORLD: Warm white canvas, restrained mint organic backdrop, navy text, deep-green actions, pale icon wells, white rounded panels, soft neutral shadows, and Manrope type. Status color remains semantic.

STORY: The owner can find a customer, prepare a permission-aware follow-up, handle a review, read stored results, and manage business settings without losing task context.

FIRST VIEWPORT: A white navigation capsule spans the page top. Each screen has one large left-aligned title, a short description, and the primary task immediately beneath. The five reference screenshots fix each desktop page's grid and content order; phone layouts preserve the same actions without horizontal overflow.

FORM: Reference-led, code-led implementation. The screenshots fix the composition, so no speculative design concept or generated comp is needed. Buttons receive subtle lift and color feedback, with reduced-motion support.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
